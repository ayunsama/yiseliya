三、完整战斗规则（照搬伊瑟利亚[战斗协议]，判定一律按此执行）
# 战况总览
1. 触发: 战斗开始或每轮开始时输出。内容: 环境地形及距离、突袭状态、地形高差与优劣骰、掩体、先攻序列、双方状态。
2. 突袭判定: 若一方未察觉，突袭方获得一个完整额外回合；被突袭方此轮防御劣化，不可动作/反应。
3. 地形规则:
   - 优势/惩罚骰: 高处攻击低处获优势骰（两次取高）；低处仰攻获惩罚骰（两次取低）；优势+劣势互相抵消。
   - 掩体: 半掩体目标防御+2；四分之三掩体+5；全掩体不可被直接瞄准。
   - 困难地形: 移速减半；地形变更（法术/技能）须在总览中注明。
# 行动执行（单轮结构）
1. 资源限制: 每角色每回合 = 移动 + 1动作 + 1附赠动作 + 自由行动（不限）；反应回合外限1次。
2. 移动: 基础速度（人类30尺/短腿25尺/兽人35尺），困难地形减半。
3. 动作类型: 攻击/施法/武技/疾走(移速翻倍)/脱离(不触发借机)/防御(防御+4)/协助/隐藏/使用物品/稳定/准备行动。
3.5. 咏唱前摇（施法者强制规则，见【魔法·咏唱前摇规则】）:
   - 施法者分「无咏唱」与「咏唱」两类：无咏唱（角色设定/命格/加护注明"无需咏唱"）直接瞬发；未注明的普通施法者一律需咏唱。
   - 咏唱施法：先花费 1 个完整动作（1 回合）吟唱（本轮只咏唱不释放），法术于施法者下一回合开始完成释放；吟唱期间受击按施法打断规则检定，失败则咏唱中断、法术失败（不扣完整 MP）。
   - 【必须念诵术式语言】咏唱必须在 RP 中念出具体咒文（主角由玩家输入咏唱内容，同伴/敌人由 GM 叙事写出咏唱片段），禁止不咏唱直接"释放XX术式"；咒文风格须与学派匹配（元素咒言/圣光祷言/暗能低语/亡者祷文/契约真名/刻印诵句/律动咏调）。
   - 简化咏唱：技能/装备注明"咏唱缩短/瞬发法术"的可压缩咏唱为附赠动作；符文系预先铭刻激活无需咏唱。
4. 附赠动作: 双持副手攻击/特定技能/喝药剂，每轮限1次。
5. 反应: 回合外限1次（借机攻击/法术反制/闪避本能/反击/护盾等）。
6. 资源消耗: 武技耗SP、魔法/神术耗MP、混合耗SP+MP；SP/MP耗尽时对应主动技能不可用，但普攻与被动不受影响；基础攻击永远免费。
# 攻击与施法结算
1. 命中检定: 近战 d20+力量/敏捷修正+熟练 vs 目标防御值；远程 d20+敏捷/智力修正+熟练；长射程或近战受干扰时劣化。
2. 地形优劣势骰: 优势投两次取高、惩罚投两次取低；与夹击等叠加时遵循"优势+劣势=抵消"。
3. 部位补正（可宣言瞄准）:
   - 头部: DC+4，伤害×1.5，暴击附加1轮眩晕。
   - 躯干: DC+0，伤害×1.0。
   - 手臂/前肢: DC+2，伤害×0.8，武器50%脱手或施法手势受扰。
   - 腿部/下肢: DC+2，伤害×0.8，移速减半1轮。
   - 翅膀/飞行肢: DC+3，伤害×0.8，飞行中断。
   - 特殊生物: 构装体头部/躯干减半；无定型生物不适用部位；体型差±2 DC。
4. 特殊掷骰: 自然20必定命中暴击（伤害骰×2）+附加效果；自然1必定未命中大失败。
5. 伤害结算: 武器伤害骰+属性修正×部位倍率；应用目标抗性(÷2)/弱点(×2)。
6. 施法打断与专注: 受击需 智力(魔法)/感知(神术) 检定 DC=10+伤害/2，失败则打断；法术也可宣言部位（直接伤害法术生效，范围法术不适用）。
7. 特殊机制: 借机攻击、夹击（优势）、冲锋（命中+1）、压制/缴械。
8. 资源消耗时机: 宣言使用立即扣除，无论命中与否；不足则无法使用。
# 生死与状态变更
1. 濒死触发: HP归零时倒地、失去意识、进入濒死。
2. 瞬间死亡: 单次过量伤害绝对值 ≥ 最大HP，直接死亡。
3. 死亡豁免: 濒死角色每轮自身回合开始时投d20：自然1（2次失败）、2-9（1次失败）、10-19（1次成功）、自然20（恢复1HP苏醒）。
4. 濒死受击: 受击计1次失败，暴击计2次失败；累计3次成功稳定昏迷、3次失败死亡。
# 战斗结束与结算
1. 触发: 一方全灭、投降或成功逃脱。
2. 经验值: 单体EXP=目标Lv×等阶战斗系数；等阶压制（超1阶无收益）；集群衰减。
3. 状态转化: 清除战斗临时增益，保留持续性创伤或诅咒。
4. 资源保留: HP/MP/SP保持当前值不自动恢复。

九、英灵规则（契约英灵存在时生效，英灵位显示在我方快照；无契约英灵时整段忽略）
1. 定位: 英灵不占独立行动轮、不参与先攻序列，随主角战局活动；每轮结算时顺带判断英灵状态。
2. 残响之力（0~100）: 我方击杀敌人时英灵汲取源质增加残响（击杀 +10~20 视敌人强度，重伤敌方 +5）；残响增减用「状态变更: 英灵名 残响之力 旧值 -> 新值」与 <UpdateVariable> 同步（路径 /英灵/残响之力）。
3. 微弱干涉（残响 < 100）: 英灵可进行低代价干涉（修正攻击轨迹、预警背后攻击、小规模守护），每次消耗 5~10 残响，按战局酌情触发，不能喧宾夺主。
